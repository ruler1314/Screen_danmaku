================================================================================
                         中文翻译浮窗 — 设计说明
================================================================================

一、目标
--------------------------------------------------------------------------------
在 Windows 上提供一个半透明、始终置顶的中文翻译浮窗。用户只输入中文，
选择目标语言后调用 OpenAI Chat Completions 兼容接口获得翻译结果。

二、界面结构
--------------------------------------------------------------------------------
┌──────────────────────────────────────────────────────────────┐
│ 设置                         中文翻译浮窗       关闭   锁定   │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                       翻译查看区                             │
│                                      翻译成 [目标语言]        │
├──────────────────────────────────────────────────────────────┤
│ 中文输入                                                     │
│ [输入中文........................................] [翻译]    │
└──────────────────────────────────────────────────────────────┘

三、交互规则
--------------------------------------------------------------------------------
1. 输入区只接受中文文本，不提供源语言切换。
2. 目标语言包含英语、日语、韩语、法语、德语、西班牙语、俄语和意大利语。
3. Ctrl+Enter 或“翻译”按钮开始翻译。
4. 翻译请求在后台线程执行，界面不会因网络等待卡死。
5. 未锁定时可以拖动浮窗边缘调整大小，最小尺寸为 620×380。
6. 锁定时主窗口整体鼠标穿透；顶部栏临时成为独立置顶窗口，设置、关闭、
   解锁和拖动仍可使用，顶部栏拖动会同步移动主窗口。

四、翻译接口
--------------------------------------------------------------------------------
默认配置：
  引擎：Google（免 Key）
  地址：https://translate.googleapis.com/translate_a/single

可选引擎：Google、MyMemory（免费）、LibreTranslate、AI 大模型。
AI 大模型默认地址：http://127.0.0.1:11434/v1/chat/completions
模型：qwen2.5:7b；密钥：留空

接口需要兼容 OpenAI Chat Completions 格式：
  POST /v1/chat/completions
  返回 choices[0].message.content

五、代码结构
--------------------------------------------------------------------------------
main.py                         程序入口
app/core/translation_service.py 翻译请求和接口配置
app/ui/float_window.py          半透明置顶窗口、锁定穿透、后台线程
app/ui/top_bar.py               设置、关闭、锁定和拖动
app/ui/translation_view.py      翻译结果和目标语言选择
app/ui/translation_editor.py    中文输入和翻译按钮
app/ui/settings_dialog.py       接口设置窗口
app/ui/style.py                 全局半透明 QSS
app/utils/click_through.py      Qt 鼠标穿透工具
