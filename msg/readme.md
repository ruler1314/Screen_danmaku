# 中文翻译浮窗

Windows 半透明置顶翻译工具。只支持“中文 -> 目标语言”，不处理其他语言到中文。

## 使用方式

1. 在顶部设置中选择翻译引擎。
2. Google 和 MyMemory 可直接使用，不需要 API Key；LibreTranslate 可填写自己的服务地址。
3. AI 大模型使用 OpenAI Chat Completions 兼容接口，默认接口是本机 Ollama：
   `http://127.0.0.1:11434/v1/chat/completions`。
4. 在下方输入中文，选择目标语言并点击“翻译”。
5. 未锁定时可拖动窗口边缘调整大小；锁定后主窗口穿透到下层应用，顶部栏仍可操作。

Ollama 是本地免费方案，需要自行安装模型，例如 `qwen2.5:7b`。也可以使用提供免费额度的兼容接口。
